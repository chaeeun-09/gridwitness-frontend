# GridWitness 사용 설명서 (화면 조작편)

어떤 메뉴에서 무엇을 눌러야 하는지만 정리했어요. 코드 설명은 `로직-사용설명서.md`에 있어요.
버튼 이름은 화면에 실제로 적힌 글자 그대로예요.

## 시작하기

1. 주소를 열면 소개 화면이 나와요. **시작하기**(또는 **스마트 마을 보기**)를 누르면 앱으로 들어가요.
2. 왼쪽 메뉴는 세 묶음이에요.
   - 모니터링: **개요**, **스마트 마을**, **실시간 분석**
   - 분석: **고장파형 분석**, **공공데이터 분석**
   - 관리: **관리자**, **설정**
3. 왼쪽 맨 아래에 상태 표시가 두 줄 있어요. 누르면 설정으로 가요.
   - **분석 서버**: 서버 정상 / 연결 안 됨 / 확인 중
   - **시뮬레이터** 또는 **실측 장치**: 지금 보는 계측값이 가짜인지 진짜인지 알려줘요.

처음 쓰는 사람은 이 순서를 추천해요. 스마트 마을에서 고장을 일으키고, 이상 이벤트를 사건으로 등록하고, 검토를 저장해요.

---

## 1. 개요 (`/dashboard`)

한눈에 보는 요약 화면이에요. 조작할 건 거의 없어요.

- 마을 전력, 전류(예상값과의 차이), 진행 중 이상 건수, 검토 대기 사건 수가 나와요.
- **이상 이벤트** 옆 **실시간 분석 →**, **최근 사건** 옆 **전체 보기 →**로 이동해요.

## 2. 스마트 마을 (`/village`)

3D 마을(주택 3 + 가로등 2)이에요. 가장 많이 쓰는 화면이에요.

### 전원 켜고 끄기

- 오른쪽 위 큰 버튼 **정전 발생**을 누르면 마을 전체가 꺼져요. 누르면 **전력 복구**로 바뀌어요.
- 명령이 장치에 전달될 때까지 "장치에 명령 전송 중…"이 떠요. 실측 장치는 2초 안에 답이 없으면 오류가 나요.

### LED 하나씩 켜고 끄기 (채널 제어)

- 3D 아래 **LED 채널 제어** 카드의 스위치로 주택 1~3, 가로등 1~2를 하나씩 끄고 켜요. 3D에서 집이나 가로등을 눌러 나오는 창에서도 **이 LED 끄기/켜기**를 쓸 수 있어요.
- 실측 장치가 연결되어 있으면 실제 채널 릴레이(D3~D7)가 동작해서 진짜 LED가 꺼져요. 장치가 상태를 보고하면 스위치가 확정돼요.
- 예전 스케치는 채널 상태를 보고하지 않아 스위치가 잠겨요. 새 스케치를 올리세요.
- 전류는 주택 구간(INA219 ①)과 가로등 구간(INA219 ②)으로 나눠서 잡혀요. LED를 끄면 해당 구간 전류가 LED 1개 분량(약 0.056 A) 줄어요.

### 채널 점검 (**부하 현황 →** 에서)

켜져 있는 LED를 하나씩 약 2초씩 꺼 보고, 그 구간 전류가 LED 1개 분량만큼 줄어드는지 확인해요.

- **정상**: 약 0.056 A 줄어요.
- **전류 없음 (단선·접촉 불량 의심)**: 거의 안 줄어요. 이미 꺼져 있던(전류가 안 흐르던) LED예요.
- **과전류 (누설·단락 의심)**: 훨씬 많이 줄어요.
- 점검이 끝나면 꺼 둔 채널은 모두 다시 켜져요. **멈추기**를 눌러도 마찬가지예요.

### 3D 화면 보기

| 하고 싶은 것 | 방법 |
|---|---|
| 돌려 보기, 확대 | 드래그 = 회전, 마우스 휠 = 확대 |
| 집·가로등 상세 | 물체를 클릭하면 상태, 위치, 마을 전류, 켜진 LED 수가 나와요 |
| 낮/밤 | **낮** / **밤** 토글 |
| 선명하게 보기 | **고화질 켜짐/꺼짐**. 켜면 효과가 좋아지는 대신 GPU를 많이 써요. 평소엔 꺼 두세요 |
| 배선 보기 | **지상 / 지하 배선** 토글, 또는 상세 창의 **지하 배선에서 보기** |

지하 배선 모드에서는 이렇게 해요.

- 부품(어댑터, 전체 릴레이, Arduino, INA219 ①②, 채널 릴레이 ①~⑤)을 클릭하면 확대되고 핀 연결 패널이 나와요.
- **핀 이름 켜짐/꺼짐**으로 핀 라벨을 보여줘요. **전체 보기**로 되돌아와요.
- 선에 마우스를 올리면 연결 정보가 나와요.

### 고장 시뮬레이션 (시뮬레이터 전용)

화면 아래 **고장 시뮬레이션** 카드예요. **실측 장치로 연결했을 땐 쓸 수 없어요**("실측 모드에서는 사용 안 함" 표시).

1. **LED 위치 고장**에서 LED를 골라요 (LED 1~5, 주택/가로등).
2. 고장 버튼을 눌러요: **LED 단선**, **누설·과전류**. 같은 버튼을 다시 누르는 게 아니라 **이 LED 복구**로 되돌려요.
3. 전원·제어·통신 쪽 고장은 LED와 상관없이 마을 전체에 걸려요: **어댑터 전압 강하**, **어댑터 전원 상실**, **릴레이 접점 고착**, **통신 끊김**.
4. **전체 복구**를 누르면 모든 고장이 풀리고 통신도 다시 연결돼요.
5. 고장을 걸면 3D 화면의 집이 말풍선으로 상황을 말해요. 카드 오른쪽 그래프는 최근 1분 전류예요.

### 이상 이벤트 → 사건 등록

- 이상 점수가 기준을 넘으면(기본 주의 0.3, 이상 0.6) 아래 **이상 이벤트** 목록에 자동으로 기록돼요.
- 줄 오른쪽 **사건 등록**을 누르면 사건이 만들어져요. 등록되면 버튼 대신 사건 번호 링크가 나오고, 누르면 사건 화면으로 가요.
- **부하(LED 5개) 현황 →**에서 구간별 전류, LED 스위치, **채널 점검**을 쓸 수 있어요. LED별 전류를 재는 건 아니고 구간 전류로 켜진 개수를 추정한 값이에요.

### 공공데이터 재생 중일 때

공공데이터 화면에서 재생을 시작하면 위에 **공공데이터 패턴 재생 중** 배너가 떠요. 시간대별 사용량만큼 LED가 켜져요. **정지**로 끝내요.

## 3. 실시간 분석 (`/live`)

- 예상 전류 대 실제 전류, 이상 점수, 경고 이력을 계속 보여줘요. 최근 구간만 그려져요.
- **판정 근거** 표에는 릴레이, 전압, 실제 전류, 예상 전류, 차이, 전력, 켜진 LED(추정), 판정이 나와요.
- 점수 읽는 법: 0은 예상대로, 1은 LED 2개 분량 이상 차이 나거나 전압이 크게 떨어진 상태예요.
- **경고 이력**에서도 이상 구간을 사건으로 등록할 수 있어요.

## 4. 고장파형 분석 (`/cases`)

AC 고장파형을 올려서 검사하고 분석하고 사람이 검토해 기록하는 곳이에요.

### 4-1. 목록

- 탭: **전체** / **검토 대기** / **검토 완료** (숫자는 건수).
- 오른쪽 위 **고장파형 등록**으로 새 사건을 만들어요.
- 사건 줄을 누르면 상세로 들어가요. 표는 사건, 출처, 데이터 점검, 단계, 등록 시각이에요.
- 서버 목록 읽기에 실패하면 오류와 다시 시도 버튼이 떠요.

### 4-2. 등록 (`/cases/new`)

1. **파형 파일** 영역에 파일을 끌어다 놓거나 눌러서 골라요. 최대 5 MB예요.
   - CSV/TXT: 열 순서가 `Ia, Ib, Ic, In, Va, Vb, Vc` 7채널이어야 해요.
   - COMTRADE: `.cfg`와 `.dat`를 **같이** 골라요. 샘플링과 주파수는 `.cfg`에서 읽어요.
2. 파일이 없으면 **샘플 시나리오로 시험하기**에서 고르세요. 그룹별 시나리오가 있고 각각 "예상: 정상/제한/거부"가 붙어 있어요. 합성 데이터라 실제 계측이 아니에요.
3. **출처와 계측 조건**을 채워요: 사건 제목, 출처 종류, 데이터셋/장비 ID, 샘플링 속도, 계통 주파수(50/60 Hz), 라벨 의미.
4. 오른쪽 아래 **등록하고 입력 진단**을 눌러요. 취소는 **취소**.
5. 하단에 현재 모델 학습 범위(1312×7, 4096 Hz, 50 Hz)가 적혀 있어요. 이 조건과 다르면 분석이 보류돼요.

### 4-3. 사건 상세 (`/cases/:id`)

위쪽 탭 네 개로 나뉘어요.

| 탭 | 하는 일 |
|---|---|
| **파형·AI 분석** | 전압/전류/영상전류 그래프(2D와 3D), **지원 여부 확인 후 실행**으로 AI 분석, 결과가 나오면 **다시 실행** / **검토 기록** |
| **입력 진단** | 행·열 수, 오류/경고 건수, 문제 목록과 고치는 방법. 문제가 없으면 **AI 분석으로**가 나와요 |
| **검토·이력** | 왼쪽 AI 결과(원본 보존), 오른쪽 사람의 최종 판단, **검토 기록 추가**, 실행 이력 |
| **원본 정보** | 파일명, 크기, SHA-256, 출처, 샘플링 등 보존된 원본 기록 |

- 입력 진단이 **거부**(`REJECTED`)면 분석 버튼이 막혀요. 진단 탭의 안내대로 파일을 고쳐 다시 등록하세요.
- 현재 서버에는 모델이 없어서 결과는 **판단 보류**로 나오고, 그 대신 "주요 근거"(피크·RMS 변화, 발생 시점, 특징 패턴)가 파형에서 직접 계산돼 보여요. 점수는 확률이 아니에요.
- 오른쪽 위 **PDF로 내보내기**는 브라우저 인쇄 창을 열어요. 거기서 PDF로 저장하면 돼요.
- "이 브라우저에는 파형이 없습니다"가 뜨면: 다른 컴퓨터/브라우저에서 등록된 사건이에요. 등록할 때 쓴 **원본 CSV를 다시 골라야** 그래프가 나와요. 파일의 SHA-256이 같을 때만 연결돼요.

### 4-4. 검토 저장

**검토·이력** 탭에서:

1. **AI 결과에 대한 판단** 고르기: AI 결과에 동의 / AI 결과와 다르게 판단 / 추가 조사 필요
2. **최종 판단** 적기 (필수로 쓰는 걸 추천), 필요하면 **추가 조사** 적기
3. **검토 저장** → "저장했습니다"가 뜨면 완료. 단계가 검토 완료로 바뀌어요.

AI 결과는 바뀌지 않고 사람 판단이 따로 쌓여요. 작업자 이름은 설정에서 정한 이름이 기록돼요.

### IoT 이상 사건

스마트 마을에서 **사건 등록**한 건 이 목록이 아니라 사건 번호 링크로 열어요 (고장파형 목록에는 안 나와요). 열면 전류/전압/이상 점수 그래프, 이상 탐지 결과, 계측 장치 정보가 나오고 같은 방식으로 **검토 기록**을 남겨요. 교류 파형으로 바뀌지 않고 DC 계측 기록 그대로 저장돼요.

## 5. 공공데이터 분석 (`/public-data`)

한전 지역·시간대별 전력사용량 패턴을 보는 화면이에요.

1. 처음엔 **기본 데이터(실제 한전 수치 아님)**가 떠 있어요. 연습용이에요.
2. 실제 데이터를 쓰려면: **CSV 양식**으로 형식을 받고, 공공데이터포털이나 한전 전력데이터 개방포털에서 받은 파일을 같은 열 이름(`지역,계약종별,월,요일구분,시간,사용량`)으로 맞춰서 **공공데이터 가져오기**를 눌러요. 가져온 뒤 점검 결과가 표시돼요.
3. **기본 데이터로** 버튼으로 연습용 데이터로 되돌아와요.
4. **지역**, **비교 지역**, **계약종별**(주택용/일반용/산업용), **월**, **요일**(평일/주말)을 골라요. 일 사용량, 피크 시간, 부하율, 패턴(평탄형/저녁 피크형 등)이 나와요.
5. 지역별 막대를 누르면 그 지역이 선택되고, **Shift+클릭**하면 비교 지역이 돼요.
6. **스마트 마을에서 재생**을 누르면 시간대 패턴이 마을 부하로 재생돼요 (시뮬레이터에서만).
7. 이 데이터는 패턴 분석용이고 AI 학습에는 쓰지 않아요.

## 6. 관리자 (`/admin`)

- **이상 탐지 기준**: 주의 기준, 이상 기준(점수), 전압 하한(V)을 바꿔요. 바로 실시간 판정과 새 사건에 적용되고 이 브라우저에 저장돼요. **기본값**으로 되돌릴 수 있어요. 주의 기준은 이상 기준보다 작아야 저장돼요.
- **활동 기록**: 모든 사건의 등록/진단/분석/검토 이력을 시각·작업자·작업·사건 순으로 봐요.
- **데이터 관리**: **사건 전체 내보내기 (JSON)**, **목록 비우기 (설정)** (설정 화면으로 이동).

## 7. 설정 (`/settings`)

| 항목 | 할 수 있는 것 |
|---|---|
| **분석 서버** | 서버 주소 수정 후 **연결 확인**. 바꿨다면 **기본 주소**로 되돌릴 수 있어요 |
| **데이터 출처** | **시뮬레이터**(가짜 계측) ↔ **실측 장치**(Arduino USB). 아래 참고 |
| **회로 구성** | 부품·배선표 확인 (읽기 전용) |
| **분석 모델** | 사용 중인 모델 2종의 데이터/입력/출력 설명 |
| **작업자** | 이름을 정하면 검토·이력에 이 이름이 기록돼요 |
| **사건 데이터** | **보관본 비우기**: 이 브라우저에 저장된 파형·기록만 지워요. 서버 기록은 안 지워지고 목록엔 다시 나타나지만 파형은 다시 등록해야 보여요 |

### 실측 Arduino 연결

1. Chrome 또는 Edge를 쓰세요. 다른 브라우저는 안 돼요.
2. Arduino를 USB로 연결하고 스케치를 올려둬요 (`arduino/gridwitness_village/gridwitness_village.ino`).
3. 설정 → 데이터 출처에서 **실측 장치**를 누르고 시리얼 포트를 골라요.
4. 연결이 되면 왼쪽 아래 표시가 **실측 장치**로 바뀌어요. 이때부터 고장 시뮬레이션 버튼은 비활성이에요.
5. 시뮬레이터로 돌아가려면 **시뮬레이터**를 눌러요.
6. 시뮬레이터에서 **끊김 재현**으로 통신 끊김을 흉내 낼 수 있어요.

## 시연 흐름 예시 (3분)

1. **스마트 마을** → **지하 배선**으로 회로 구조를 보여주고 **지상**으로 돌아와요.
2. **정전 발생** → 마을이 꺼져요 → **전력 복구**.
3. 고장 시뮬레이션에서 LED 하나를 골라 **LED 단선** → 이상 점수가 오르는 걸 **실시간 분석**에서 확인.
4. 스마트 마을 **이상 이벤트**에서 **사건 등록** → 사건 화면에서 **검토 기록**을 저장.
5. **고장파형 분석 → 고장파형 등록**에서 샘플 시나리오를 골라 **등록하고 입력 진단** → 진단 → 분석 → 검토.
6. **공공데이터 분석**에서 지역/월을 골라 **스마트 마을에서 재생**.

## 자주 막히는 곳

| 증상 | 이유와 해결 |
|---|---|
| 왼쪽 아래 "분석 서버: 연결 안 됨" | 서버가 꺼졌거나 주소가 틀렸어요. 설정에서 **연결 확인**. 접속 주소가 서버 CORS 허용(`jyx-07.github.io`, `localhost:5173`)에 없으면 막혀요 |
| 고장 버튼이 눌리지 않아요 | 실측 장치 모드예요. 설정에서 **시뮬레이터**로 바꾸세요 |
| AI 결과가 항상 "판단 보류" | 지금 서버에 분석 모델이 연결되어 있지 않아요 (정상 동작) |
| "이 브라우저에는 파형이 없습니다" | 원본 CSV를 다시 고르세요 (4-3 참고) |
| 분석 버튼이 비활성 | 입력 진단이 거부됐어요. **입력 진단** 탭의 안내를 따르세요 |
| 3D가 버벅여요 | **고화질**을 끄세요. 탭을 숨기면 렌더링이 멈춰요 |
| 사건이 다른 브라우저에 안 보여요 | 목록은 서버에서 오지만 파형·진단 상세는 등록한 브라우저에만 있어요 |
| 실측 연결 버튼이 비활성 | Web Serial 미지원 브라우저예요. Chrome/Edge로 여세요 |
